# Interpretable Trees and Regression

This project explores interpretable classification and regression with two datasets.

- Build and prune decision trees for the acute inflammation diagnosis data, then express the results as readable rules.
- Use the Communities and Crime data to compare regression approaches, including linear regression, Ridge, LASSO, PCR, and boosting.

<a id="中文"></a>
# 可解释决策树与回归

本项目使用两个数据集探索可解释分类与回归。

- 在急性炎症诊断数据上训练并剪枝决策树，再将结果整理为易读的规则。
- 在 Communities and Crime 数据上比较线性回归、Ridge、LASSO、PCR 和 Boosting 等回归方法。
